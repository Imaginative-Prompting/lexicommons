# Reporting a security problem

If you find a way into someone else's account or data, around the site's checks, or into anything that should be private,
please tell us privately before telling anyone else:

- **On GitHub:** this repository's Security tab → "Report a vulnerability".
- **By email:** imaginativeprompting@gmail.com, with "Lexicommons security" in the subject.

Say what you found, how to reproduce it, and what it lets someone do. We'll answer, fix what's real, and thank you for it
(by name, if you'd like).

Please:
- test only with accounts and data of your own, or on your own copy (`npm run local`, see [docs/self-host.md](docs/self-host.md));
- don't overload https://lexicommons.com, read other people's data, or keep anything you came across;
- give us a reasonable time to fix it before making it public.

What's covered: the code in this repository and the site it runs, https://lexicommons.com. A copy someone else hosts is
theirs to fix, though we'd like to hear about a problem that's in this code.
